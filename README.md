# Jodchha

**Connect. Discover. Go.**

Jodchha is a web platform for discovering useful websites, online services, and tools.

## Project

- Frontend: Next.js + TypeScript
- Backend: Django + Django REST Framework
- Database: PostgreSQL
- Deployment: Docker + cloud hosting

## Features

- Website directory
- Website categories
- External website redirection
- URL shortener
- QR generator
- Click analytics
- SEO-friendly pages
- Monetization through advertising, affiliate links, and sponsored listings
